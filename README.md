# 🤖 Jarvis 2.0 — Telegram Bot для СРМК

Telegram бот для студентов Ставропольского ракетно-космического колледжа (СРМК).
Работает **быстро**, **без базы данных** и **без необходимости авторизации на сайте Moodle**.

---

## ✨ Возможности

- 📋 **Расписание занятий**:
  - Мгновенный просмотр расписания для группы по умолчанию (П-31)
  - Отображение времени пар, предметов, преподавателей, кабинетов и подгрупп
  - Динамическое определение группы из заголовка Moodle

- 👁️ **Поиск преподавателя**:
  - Параллельный поиск по всем группам колледжа (1-4 курсы + ОППО)
  - Группировка расписания по дням недели
  - Сортировка по номеру пары
  - Подсчет найденных пар и охваченных групп
  - Время поиска: ~5-15 секунд

---

## 🛠️ Стек технологий

- **Python 3.10+**
- **aiogram 3.15+** (современный асинхронный фреймворк)
- **aiohttp** (асинхронные HTTP-запросы с повторными попытками)
- **BeautifulSoup4** (парсинг HTML расписания)
- **python-dotenv** (конфигурация через `.env`)

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/wolkhgames-crypto/jarvis-2.0.git
cd jarvis-2.0
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```env
# Токен бота от @BotFather (обязательно)
BOT_TOKEN=your_telegram_bot_token_here

# Белый список Telegram ID через запятую (если пусто - доступно всем)
ALLOWED_USERS=2035205294

# ID группы по умолчанию для расписания (238 = П-31)
DEFAULT_GROUP_ID=238
```

### 3. Запуск бота

```bash
python bot.py
```

## ☁️ Деплой (Bothost / Railway / Render / VPS)

### Bothost:
1. Подключите репозиторий GitHub: `wolkhgames-crypto/jarvis-2.0`
2. В переменных окружения (Environment Variables) укажите:
   - `BOT_TOKEN`: ваш токен Telegram
   - `ALLOWED_USERS`: ваш Telegram ID (опционально)
3. Главный исполняемый файл: `bot.py`
4. Запустите сервис.
